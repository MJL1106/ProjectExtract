# ProjectExtract

A single-player tactical extraction shooter built in Unreal Engine 5.7, submitted as an MSc Computer Games project.

The player infiltrates a compound, rescues a captive, and fights their way out to extraction alongside an AI companion they command through three behaviour modes and a set of orders. The enemy force is eight archetypes running on one shared behaviour tree, coordinated into squads and paced by a director system that controls when reinforcements arrive.
